# Apex Insect

Refactored from a single `index.html` to a modern Vite + Vanilla JS project.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Structure

- `src/main.js`: Entry point, input handling, and game loop.
- `src/game/`: core game logic (`Ant`, `Leg`, `Environment`, `Vec2`).
- `src/style.css`: Project styles.
